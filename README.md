# Small Members Tab

**Additional modifications made by NightCross00**

This repo was originally forked from Beard Design because it stopped working and it didn't seem hopeful that any updates will be coming
and I really like the collapsible/auto-expanding memberlist especially when I have tiny discord sizes due to small monitors, so I tried
updating this myself.

I fixed as much of the original intended functionality as I could, and eventually over the years added a few tweaks of my own for
small discord windows Quality of Life improvements.


This is really more like Small Member Tabs + other various CSS tweaks for small Discord windows

Additional changes:
  - Fixed Screen share modal's buttons going outside of viewport (Added scrollbar to modal to fix this issue)
  - Move spectator's element further to the left so it is not obscured by the stream's quality text pill element (the `1080p 60FPS` text)
  - Increased width of Notification/Inbox Popout by 200%
  - Added documentation for what each CSS modification does


*Disclaimer, I'm not a professional when it comes to CSS magic*
